The final dogfood test

Shine rebuilt Shine.

The old page was accessible and honest, but it buried the product in a narrow technical essay. V4 began with that evidence—not a mood board—and moved the proof into the first screen.

The V4 architecture

Keep shadcn. Add direction.

A primitive library cannot create a point of view. V4 keeps shadcn as the composition layer, chooses Base UI or React Aria beneath it when appropriate, and adds the page references, art-direction contract, and proof loop that component libraries do not supply.

01 / DIRECTOR

Shine

Diagnosis, retrieval, composition archetype, image strategy, signature moment, anti-repetition, and proof.

02 / COMPOSITION

shadcn/ui

Owned source, adaptable components, and a foundation that does not trap the product in a vendor theme.

03 / PRIMITIVES

Base UI + React Aria

Base UI by default for greenfield work. React Aria when complex interaction, internationalization, or accessibility demands it.

04 / REFERENCES

Pages before atoms

Untitled UI, Magic UI, Motion Primitives, Tremor, and authored blueprints contribute licensed source or cited region structure—never an unexplained costume.

05 / OUTPUT

Native to the medium

Web components for web, editable shapes for PowerPoint, print structure for PDF, and conservative email HTML.

The working loop

Six gates. One coherent result.

V4 separates structure, interaction, paint, and proof so an agent cannot satisfy a design request by changing border radii and calling it original.

01 / LOOK

Render before opining

Inspect the actual page and record a baseline screenshot.

02 / NAME

Write the defects

Usability and completeness outrank composition and craft.

03 / MATCH

Choose a page

A composed reference supplies regions. One family gets one shortlist slot.

04 / DIRECT

Make a specific decision

Name the archetype, image strategy, signature moment, and what must not repeat.

05 / BUILD

Honor the host

Use the installed component system and complete every interaction contract.

06 / PROVE

Exercise the job

Measure pixels, run accessibility, walk the primary flow, and compare to the cite.
